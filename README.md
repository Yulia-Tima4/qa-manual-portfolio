# 🧪 QA Manual Portfolio

Портфолио артефактов ручного тестирования на примере публичного сервиса **[Lomonosov School](https://portal.lomonosov.school)** — онлайн-школы подготовки к ЕГЭ и ОГЭ.

> Здесь собраны реальные примеры моей работы: чек-листы, тест-кейсы, баг-репорты и техники тест-дизайна.

---

## 📂 Что внутри

| Раздел | Что смотреть |
|---|---|
| [**Чек-листы**](checklists/) | Проверки пользовательских сценариев: магазин, авторизация |
| [**Тест-кейсы**](test-cases/) | Детальные шаги проверок с ожидаемым результатом |
| [**Баг-репорты**](bug-reports/) | Оформленные дефекты с шагами, severity и priority |
| [**Тест-дизайн**](test-design/) | Техники тестирования на примере реальных полей |

---

## 🎯 Что тестируется

**Сервис:** Lomonosov School — онлайн-школа подготовки к ЕГЭ/ОГЭ<br/>
**URL:** [portal.lomonosov.school](https://portal.lomonosov.school)<br/>
**Тип:** веб-приложение

**Ключевые пользовательские сценарии:**
- Покупка курса (магазин: направление → программа → предметы → авторизация)
- Регистрация и авторизация через Email, VK, Telegram, Discord, Apple
- Личный кабинет: верификация аккаунта, доступ к курсам
- Подтверждение email

---

## 🛠 Что я использовала

- **DevTools** — анализ запросов и вёрстки
- **Postman** — проверка API
- **SQL** — валидация данных в БД
- **Kibana / Sentry** — анализ логов
- **Charles** — анализ трафика
