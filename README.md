# 🧪 QA Manual Portfolio

Портфолио по ручному тестированию: анализ пользовательских сценариев, тестовая документация, баг-репорты и ретестирование.

## Проекты

### Lomonosov.school
**Практический опыт работы с образовательным веб-сервисом**

- Разбор обращений пользователей и воспроизведение проблем.
- Проверка регистрации и верификации профиля.
- Работа с проблемами доступа к курсам, Email и Telegram.
- Передача подтверждённых проблем IT-команде.

**Артефакты:**
- [Чек-листы](checklists/)
- [Тест-дизайн формы регистрации](test-design/)

### Hiiire
**Стажировка по ручному тестированию HR-сервиса**

- Подготовка тестовых данных для проверки обработки резюме в форматах PDF, DOC и TXT.
- Оформление баг-репортов и рекомендаций.
- Повторная проверка дефектов и регрессионное тестирование.

**Артефакты:**
- [Баг-репорты](bug-reports/)

## О документации

В репозитории представлены материалы из практического опыта и отдельно подготовленные примеры тест-дизайна. Для каждого артефакта указан соответствующий контекст; учебные примеры не выдаются за результаты выполненных проверок.
